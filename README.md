
# Fields for Nodes
All element fields are written in *lower-case*

Within a *Data* element:
1. ID, 
2. Label
3. Level
4. Description
5. Video / Image
6. References
    1. Title
    2. URl
7. Pseudocode

# Fields for Edges
Within a *Data* element:
1. ID
2. Source
3. Target
4. Relationship
    - Contains
    - Related to
    - Is a part of
